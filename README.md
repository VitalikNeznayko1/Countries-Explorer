# 🌍 Countries Explorer

A React application that allows users to explore countries around the world, view detailed information, and apply filtering, sorting, and pagination. The data is fetched from the REST Countries API.

## ✨ Features
- 🌍 Browse a list of countries
- 🔎 View detailed information about a selected country
- 🗣 Filter countries by language
- 🌐 Filter by continent and region
- 🔃 Sorting options:
  - by ID
  - alphabetically (A–Z / Z–A)
- 📄 Pagination
- 🔙 Navigation between pages
- 💾 Persist current page number

## ⚙️ Installation
```
git clone https://github.com/VitalikNeznayko1/Countries-Explorer
cd countries-explorer
npm install
npm run dev
```
